# QA 自动化网页教材

直接用浏览器打开 [index.html](index.html)，无需安装阅读软件或联网。推荐从第 1 章开始，按章节学习；左侧可搜索中文、英文术语和方法名。

- 19 章，约 2.4 万个汉字，另含英文、35 处原代码片段、29 个折叠答案。
- 章节目录、章内导航、搜索、明暗主题、字号调整、已读标记。
- [Markdown 合集](QA_AUTOMATION_TEXTBOOK.md) 适合交给教学聊天或自己编辑。
- [原代码全览](source.html) 包含 41 个源文件，代码引用可跳到对应行。
- chapters/ 是每章的 Markdown 阅读版；manuscript/ 是作者稿，包含源码提取标记。
- source-manifest.json 记录生成时间与源文件哈希。代码变更后需重新生成，网页不会偷偷同步变化。

阅读位置按章节、已读标记和外观偏好保存在浏览器本地，不跨设备同步；禁止本地存储时正文仍可读。已读不是掌握程度评分。

## 重新生成

在项目根目录执行：

```powershell
python docs/textbook/build_textbook.py
```

生成器需要 Python 的 Markdown、Pygments 包；当前环境已具备。阅读产物不需要这些依赖。生成过程不会运行业务测试，不会修改 Java 源码。

## 内容边界

根据当前 V5 代码解释。三个被测系统彼此独立，未实现 Appium；GitHub 工作流已配置但尚未云端实跑。教材区分已有功能、局限与待实现练习，不能把练习算入业务场景数。
